# Is It Really the Bank? / Это правда банк?

**THE CIS SPRINT · Dubai · Protect the little guy: human & transaction**

Two incoming calls display the same name. The customer opens the banking app to check whether the call centre has an active outreach record. An on-device text classifier answers questions about the result in Russian or English. A matching record confirms the outreach only. The external caller’s identity remains unknown.

**Run it:** download the repository as a ZIP, extract it, and double-click **index.html**. Select **EN** for English. The entire demo runs offline, including the classifier. The support chat, call sessions and outreach records are synthetic.

[Watch the 56-second demo (RU captions)](https://drive.google.com/file/d/1nQdzAscv4F-odgBBxqy6PiqWb5xhcpX2/view?usp=drivesdk) · [Seven-slide pitch in Russian](presentation/pitch-ru.pdf)

Независимая концепция для THE CIS SPRINT, трек Protect the little guy: human & transaction. В качестве примера указан Mashreq NEO; этот прототип не создан банком, не использует его интерфейс или сервисы и не заявляет об уязвимости.

## Запуск

Откройте `index.html` двойным щелчком. Сервер, установка и интернет не нужны. По умолчанию интерфейс русский; кнопка **EN** вверху переключает подписи для жюри.

Путь на главном экране приложения: **«Это правда банк?» → «Банк сейчас мне звонит?»**. Слева показан вымышленный входящий вызов с одинаковым именем Mashreq во всех сценариях. Справа выберите сценарий. Повторный выбор создаёт новую синтетическую сессию.

## Как посмотреть ИИ в действии

Выберите «Обращение банка», нажмите «Банк сейчас мне звонит?» и откройте пример вопроса об имени звонящего. Затем введите «Что мне делать дальше?». Модель определит другую тему, а банковский статус останется прежним. Чтобы увидеть отказ, переключитесь на «Другой вызов» в пограничном сценарии.

## Логика и границы

Локальный симулятор создаёт запись с синтетическими идентификаторами клиента и текущего вызова. Проверка требует совпадения обоих идентификаторов и срока действия 60 секунд. Доступны тесты просрочки, другого вызова и другого клиента. Название звонящего служит только декорацией. При результате «Найдено обращение банка» подтверждена лишь запись в симуляторе; подлинность внешнего звонящего не установлена. Перед переходом в чат соответствие проверяется ещё раз.

Панель **AI-пояснение · офлайн** появляется внутри приложения после проверки и принимает вопросы на русском и английском. Для быстрого показа есть кнопка с примером вопроса. При загрузке страницы небольшой классификатор обучается на размеченных примерах четырёх тем: имя звонящего, статус проверки, следующий шаг и приватность. Он выбирает одно из заранее написанных безопасных пояснений; при неясном вопросе выводит запасной текст. Это классификация текста, не генеративная модель. Решение о статусе звонка принимает только описанная выше проверка записи. Пояснение сбрасывается при смене сценария, языка и истечении подтверждённого обращения. Можно спросить: «Звонящий назвал моё имя и последние цифры карты. Он точно из банка?» или «I already hung up. What should I do now?»

Чаты, вопросы и ответы существуют только в памяти открытой страницы; перезагрузка удаляет их. Нет доступа к телефону, контактам, микрофону, банковским данным, OTP, счетам, платежам, API, базе данных, сети или реальной отправке сообщений. Сумма и карта на главном экране условны, без реквизитов. Перезагрузка сбрасывает демо. Devin предложил два тестовых вопроса выше, написал безопасное пояснение о границе проверки личности звонящего на русском и английском и предложил регрессионную проверку истечения 60-секундной записи. Devin использовался как инструмент разработки, не входит в работающий прототип.

Для реального продукта нужны приложение с подтверждённой сессией клиента, серверный источник обращений банка, надёжная привязка к конкретному вызову и защищённый канал связи. Без такой привязки можно подтвердить только факт обращения. Контекст: [памятка Mashreq о мошеннических звонках](https://www.mashreq.com/uae/neo/security/card-safety/).

## Проверка

В этой папке: `node --test test.mjs`. Тесты проверяют отсутствие записи, срок действия, совпадение клиента и вызова. Для проверки кликов в локальном Chrome запустите отдельный профиль:

```sh
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --disable-background-networking --no-first-run --user-data-dir="$(mktemp -d)" --remote-debugging-port=9222 about:blank
```

В другом терминале: `node test-browser.mjs 9222`. Проверяются русский и английский язык, оба пути в чат, все пограничные случаи, одинаковое имя вызывающего, вопросы для классификатора, запасной ответ, приватность, видимость результата и AI-поля на мобильном экране, отсутствие устаревшего положительного статуса после вопроса и отсутствие горизонтальной прокрутки на ширине 1150 и 375 пикселей. Для проверки TTL тест переводит запись к отметке +59,2 секунды и наблюдает автоматическое исчезновение положительного статуса, старого AI-пояснения и кнопки связанного чата после +60 секунд.
